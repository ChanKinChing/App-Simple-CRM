# Simple CRM

中小企業客戶管理系統（個人作品集專案）。

- 後端：Spring Boot 3.5.16 / Java 17 / Maven
- 資料庫：PostgreSQL 17
- 前端：React + Vite（開發中）
- 認證：Spring Security + JWT

本專案仍在建置中，功能與進度見 `PLAN.md`。
